# 平面连杆装配分支追踪分析台

在浏览器中绘制含 **1 或 2 个闭环** 的平面杆铰网络，后端（FastAPI + SciPy + SQLite）
从初始构型出发对全部杆长约束做连续延拓求解，返回各关节轨迹与误差不超过 **0.1°**
的可达角段边界；同一驱动角存在多解时始终留在原装配分支，遇到奇异汇合会暂停并
展示后续候选位形，由用户选支后续算，无候选则终止该角段，且绝不跨不可达角段插值。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

然后用浏览器访问：**http://localhost:8000**

SQLite 数据库持久化在名为 `linkage-data` 的卷中；停止用 `docker compose down`。

## 本地开发启动（不用 Docker）

```bash
pip install -r backend/requirements.txt
cd backend
uvicorn app.main:app --reload --port 8000
```

浏览器同样访问 http://localhost:8000 。运行测试：

```bash
pip install -r backend/requirements-dev.txt
cd backend && python -m pytest tests/
```

## 使用说明

1. **绘制机构**：工具栏选择「+固定铰点」「+动铰点」在画布上放置关节；
   「+连杆」模式下依次点击两个关节创建连杆（长度默认取当前距离，可在右侧面板修改）；
   「选择/拖动」模式可拖动关节、点选连杆；「删除」模式点击关节或连杆删除。
   也可以直接点击「示例」载入一个 Grashof 曲柄摇杆机构。
2. **设定驱动**：在右侧连杆表中用单选钮选择**连接固定铰点与动铰点**的连杆作为驱动杆
   （驱动杆绕固定铰点旋转），并填写驱动角度范围 θ_start ~ θ_end（度）。
   驱动初始角由曲柄端点的初始坐标自动反算，必须落在角度范围内。
3. **分析**：点击「分析」。出现以下情况会被拒绝并提示原因：
   初始构型不闭合、机构非单自由度（2×动铰点数−连杆数 ≠ 1）、杆长非正、
   引用无效（连杆/驱动杆指向不存在的元素）、闭环数不是 1 或 2、机构不连通等。
4. **选支**：若追踪在奇异汇合点暂停，画布上以彩色虚线叠加显示各候选位形，
   在右侧点击「选择候选 N」后续算；若奇异点之外无任何候选位形，该角段在
   边界处终止（边界误差 ≤ 0.1°）。
5. **播放**：点击「播放」按可达角段顺序动画演示机构运动，角段之间（不可达区间）
   直接跳过并提示，绝不插值；画布同时绘制各动铰点轨迹曲线与角段边界标记。
6. **修改即失效**：任何对机构的修改（拖动关节、改杆长、改角度范围等）都会使
   旧轨迹立即失效，需要重新分析。

### 想观察“暂停选支”？

把示例四连杆改为**非 Grashof**（如曲柄 150、连杆 200、摇杆 200、机架 340），
曲柄无法整周转动，分析会在可达角段边界终止。再进一步加一组二杆组
（第 3 个固定铰点 + 1 个动铰点 + 2 根杆，构成第 2 个闭环），并让二杆组在行程中
相切，而主轴另一装配分支在其外仍有解，即可看到奇异汇合暂停与候选选支。

## API 简介

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/analyze` | 提交机构 JSON，校验并启动追踪；校验失败返回 422（`detail.code` / `detail.message`） |
| POST | `/api/sessions/{id}/choose` | 暂停会话中选定候选位形（`{"candidate_index": N}`）续算 |
| GET | `/api/sessions/{id}` | 查询会话当前状态 |
| GET | `/api/health` | 健康检查 |

机构 JSON：

```json
{
  "joints": [{"id": 1, "x": 0, "y": 0, "fixed": true}, {"id": 3, "x": 50, "y": 86.6}],
  "links": [{"id": 11, "a": 1, "b": 3, "length": 100}],
  "driver": {"link_id": 11, "theta_start": 0, "theta_end": 360}
}
```

分析响应包含：`segments`（角段，含逐采样点的全部动铰点坐标与终止原因）、
`paused`（奇异点角度与候选位形）、`messages`（含中止原因）、`moving_joint_ids`
（坐标展开顺序）等。

## 技术要点

- **约束求解**：未知量为除曲柄端点外的动铰点坐标，方程为归一化杆长约束
  （单自由度时恰为方阵）；Newton（回溯线搜索）为主、SciPy `hybr` 兜底。
- **分支保持**：小步长预测-校正 + 步内跳变量检测，同一驱动角多解时不会跳支。
- **奇异处理**：监测 Jacobian 行列式变号与求解失败，二分定位边界至 ≤0.1°；
  在边界外以「外推 / 单关节反射 / 组合反射 / 确定性抖动」多种子搜索候选位形。
- **持久化**：机构与会话状态（角段、前沿队列、暂停现场）存入 SQLite，
  选支续算可跨请求恢复。
